# Reference relationships in short drama

A connected reference supplies selected facts, not every property of its picture. The character owns identity, the current look owns costume/hair, the scene owns usable space, the palette owns color roles, and adopted shot state owns the next entry. Name duties and exclusions at [ASSETS](../../creation/asset-plan.md) and carry them into the [real bindings](../../production/reference-scopes.md).

## Let one picture open another view

A shared encounter frame can establish scale, axis and contact before a close-up. Reverse coverage sees the same room from another camera: keep entrances, fixed furniture and physical light, while projecting them from that camera's location. Do not copy the same backdrop behind both opposing characters. A listener's identity comes from their own accepted asset, not from blending the speaker's face.

The [four-panel character masters and on-demand location/state images](../../creation/drama-reference-sheets.md) organize reusable facts. Each new shot selects appropriate clean panels or a derived integrated frame. Record the master/panel/crop/version relationship; avoid borders, duplicate people and diagram marks in the result. Shot order, request boundaries and grid order are separate choices.

## Continue only the facts the new picture needs

If a character leaves an argument holding a phone, the hallway can retain their identity, current outfit, hand and phone state while showing a different connected space. A later day can deliberately change costume and lighting while the same person persists. Treat transformation, injury, wetness and prop reveals as explicit states rather than unexplained reinvention.

A neutral portrait does not supply expression rhythm, a scene-empty plate does not establish interpersonal contact, and an old frame does not establish the latest adopted state. When predecessors are actual continuation inputs, use accepted media and selected intervals, not a discarded tail or provisional candidate.

## Carry the world into motion

[Image direction](image-direction.md) establishes the static picture; [video direction](video-direction.md#let-footage-carry-temporal-behavior-that-matters) describes temporal behavior and actual supported footage controls. Use a single clean first/last frame when the mode requires it. Give the smallest coherent reference set that covers necessary identity, composition, state and look within actual route limits; uploading the entire library does not establish better consistency.
