# H3过程的展开深度

写每条H3正文前与[H3提示词](h3-prompts.md)一起读；实际写作接口自动携带本页。先充分设计、展开，再删除无效重复。

## 从导演决定到播放过程

逐镜检查以下维度中实际承担表达的内容；沿用STORYBOARD和已接受设计，在现有分镜里主动发展具体选择。

| 维度 | 正文应让生成端知道什么 |
| --- | --- |
| 构图与空间 | 景别、机位高度/工作侧、前中后景、人物与道具位置；开场是否为目标运镜留下空间 |
| 人物与听者 | 触发、角色采取的行动、接触/重心与停顿、听者同时做什么、反应如何被当前景别看清 |
| 摄影与焦点 | 起始画面、运动触发、方向/路径、必要幅度与速度、视差或遮挡变化、焦点由谁转到谁、停在哪个画面 |
| 光源与材质 | 世界光源及软硬/明暗关系，脸与关键物件怎样受光，转身/移动/接触时的光影和材质反馈 |
| 声音与节奏 | 谁发声、声源距离、动作同步、停顿底声、声音让路与声桥；逐字对白只出现一次 |
| 出口与邻镜 | 结束姿态、手与持物、视线/屏幕方向、信息揭示及可剪落点；保持既定镜头边界 |

每个有效指令尽量回答“什么触发→谁/什么改变→观众看见或听见怎样的变化→在哪里结束”。例如转焦需近远两个可见平面、注意转移的触发、清晰度交接和终点；仅写rack focus不够。固定构图发展画内调度，运动构图发展空间与观看立场；以体验选择并组合。

一个主导戏剧变化可由人物、听者、相机、焦点、环境及声音协同完成，不限制只能有一条并行通道；明确谁先谁后、哪些同时，避免同一身体部位的互斥行动、遮住关键表演或超过时长。不要为了减少动作数删掉必要的反应和受光变化。

## 场景持续状态不能缺省丢失

按自动加载的[场景视听调度](../../creation/audiovisual-orchestration.md)，逐镜承接持续环境、听者反应、物理余动与声画注意关系。没有单独剧情作用的环境活动仍可承担生活感；不要把“服务主体”解释成只有主角能动。环境停住应有物理或戏剧依据。具体选项留在上游分镜，编译不新增天气、道具、人物或情节。

## 展开深度与回读

Ref2VA通常以detailed_description的350–500英文词为展开参考，单镜不自动缩短；不是六段总词数，也不是每切的配额。短于参考时检查是否漏掉有效决定，长于参考时检查重复和冲突，不机械补词或截断。Base模式按完整可见可听过程展开。

回读实际提交正文：逐项找到上游已选构图、表演、摄影、光照、声音、出口的落地句。只在STORYBOARD里存在、正文却没表达的动态决定，应补回；确由参考承担的静态事实只需明确载体。缺少必要设计时回到原所有者补齐，不在编译时擅自加剧情。时间戳和器材词不是精确执行保证。


## 参考负责静态事实，正文负责差异与过程

已核实参考承担身份、当前造型、空间和基础光色；正文仍需建立当前取景与动作条件，并展开动作、可见变化、声音和注意力。静图不能代替移动中的视差、转身受光、焦点交接、接触阴影和声音远近。只删除重复外观，不删除这些动态控制；参考含糊、需要改变或存在具体冲突时补限定。

过程的精度由看点决定：递出→接触→松手→接住，或眼先动→头转→听者停手，分别写清承担戏剧意义的阶段和同时发生的反应。细微表演安排在能读到它的景别；必要的持物手、接触顺序、隐藏/揭示条件始终可定位。

复杂动作放不进当前时长时改覆盖或拆块。返回平淡时先区分：故事没有变化、参考压住表演、请求缺少具体过程、模型未执行，还是剪辑丢了反应；修最早失效的部分。
