# Directing short-drama video

Use the current shot/experience card and its relevant [five-document facts](../../creation/drama-preproduction.md). Use [expressive direction](../../creation/aesthetic-direction.md), [scene design](../../creation/scene-design.md) and [director blueprint](../../creation/director-blueprint.md) to develop the viewing approach; use the selected [H3 format](h3-prompts.md) to compile it. Reuse already-read unchanged guidance. Photographic choices follow [cinematic look](../../creation/cinematic-look.md) when that question arises; the actual route remains [RunningHub H3](../../production/runninghub-h3.md).

## Let footage carry temporal behavior that matters

A still establishes a pose, person, prop or space; an unfolding action also has preparation, contact, weight, rhythm and release. When a source or rehearsal clip should carry that behavior, use it as an actual input only if the selected app exposes that operation. Watching source footage for analysis is different from binding it to generation. If the route lacks that control, retain the clip as planning evidence and test precise text, accepted compositions and H3 coverage honestly.

Choose useful excerpts with the action's setup and settling where needed. Do not connect unqualified original cast/world/sound if those should change. Define retention and exclusions explicitly; verify leakage and the target experience in an actual result. [Reference relationships](generated-dependencies.md) owns continuing identity and world; [input controls](../../production/request-controls.md) owns actual transport semantics.

## Direct the reason for an action

Stimulus, objective and tactic make performance legible. A character can hide pride, challenge an accusation, notice danger or try to save face; each has a different gaze, posture, voice and effect on the listener. Write the critical onset/peak/hold/release and concurrent listener response. Stillness and broad comedy both need a reason and the intended intensity. Preserve the source experience while allowing a stronger target mechanism under the [fidelity contract](../../creation/fidelity-contract.md).

## Ground actions in the generated scene

Describe actual body/hand/prop relationships, contact points, movement paths, reveal permissions and ending state. Separate a metaphor in dialogue from a literal visual event. Camera motion has motivation, geometry, timing and a landing; a cut has a dramatic job. Build the full process from [the directing card](../../creation/director-blueprint.md), then compile into official H3 fields. Detailed process can be long when it controls required multi-beat action; remove repetition, not consequential information.

Generated action and post effects have different prerequisites. A blush overlay needs a readable face and timing; a match cut needs compatible exit/entry states; an insert needs a native clear view of the evidence. Do not promise post can restore ungenerated contact or unseen room geography. Chroma/matting can serve a specifically assigned effect, with processed media inspected against its final background; it is not the default replacement for integrated scene generation.

## Give each input its responsibility

| Input | Responsibility |
| --- | --- |
| Character sheet / selected panel | Accepted identity and current look, excluding panel borders and neutral pose when it is time to act |
| Scene sheet / selected view | Geography, scale, materials and base light; not nine sequential shots |
| Prop/state frame | Shape, grip, state and visibility/reveal permission |
| Clean first/last frame | Exact endpoint composition when the verified mode supplies that control |
| Source/rehearsal footage | Selected temporal, contact, acting or camera behavior when supported |
| Voice/dialogue | Named speaker, words, intended vocal identity/delivery and timed listening response |
| Palette/hero frame | Color roles and accepted look, not flat swatch styling |

Prompt prose does not upload media or turn a reference slot into first-frame or exact-audio drive. Select inputs from current app evidence, then reverse-read the final serialized request. Model completion is not acceptance.

## Direct camera and cuts as part of the passage

A Segment is a performable dramatic passage, not one speaker turn or one camera shot. One H3 block may contain related turns/cuts; several blocks may meet at meaningful cuts while preserving the scene. Continuous action is a creative requirement only where the chosen experience needs it. A grid is not automatically a sequence controller.

Shape cuts around anticipation, surprise, reaction and emotional release. Explore matching geometry, movement handoffs, occlusion, subjective time and sound bridges as shot groups; give generation the required exit/entry frames and post the exact operation. Project light into each camera from the same physical source; retain plausible scale/axis across reverse views. [Shot blocks](../../production/shot-blocks.md) owns block boundaries and adopted state handoff.

## Size the request around the delivery

Read/perform target dialogue at the intended pace; use `hypit measure` following [script/time](../../creation/script-and-time.md#measure-before-choosing-durations). Reserve action, interruption, reaction and quiet time. Current app lengths constrain requests, not story scenes. Split at a motivated boundary if overloaded; do not discard a joke pause or rush speech to fit.

After generation, actual aligned media supplies word time and duration. Inspect single/pair/scene playback, choose real in/out intervals and update continuation state. [Voice/performance](voice-and-performance.md) owns speech/coverage relationships and [scene acceptance](../../production/scene-acceptance.md) owns what can actually be adopted.
