# Narrative text and graphic composition

Read [post design](../../production/post-design.md) for exact glyph/title reveal, ownership and
executable source/alpha/mask handoff. Build the accepted most-readable visual state first,
then implement its contour/mask/material/hold/exit as the actual design requires.

Use the visual manual and actual source/Brief to decide whether a title, message, in-world display, designed facial accent or graphic reveal belongs. Each contribution has a dramatic trigger, focus, reading interval, departure and relationship to people/action/sound. Typography should not cover the evidence or listener needed to understand the scene.

Separate photographed scene content from independent graphics: a physical note travels with the hand and world; an added title has its own semantic/clock placement and visual material. A readable proof item needs authored exact wording and suitable coverage. Apply local clean-asset exclusions without deleting purposeful final writing or effects.

Record type hierarchy/material, occupied area, safe placement, [palette roles](../../creation/style-lock.md), perspective/tracking when needed, and sound/neighbor handoff. Preserve the experience of a source title passage while allowing better target execution; an unrelated subtitle preset is not equivalent merely because it has the same words.

[Fonts/text](../../production/fonts-and-text.md) owns font resources and exact Typography; [spatial](../../production/spatial.md) owns geometry/fitting; [component design](../../production/component-design.md) owns implementation. [Motion/effects](motion-graphics.md) owns temporal behavior. Judge real overlap, glyphs and reading rhythm in the encoded scene, not only in a layout screenshot.
