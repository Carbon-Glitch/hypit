# 参考图声各自控制什么

选图、绑定或修复参考冲突时读。每项在既有ASSETS/REFERENCE_PLAN记实际文件与版本、输入槽位、用途和适用镜头。人物图管身份/造型，场景图管地理，当前构图图管本镜起点；音频区分声线参考与真实信号复用。

## 先写用途，排除项按需

`allow`列当前输入实际承担的内容；`deny`默认空列表。只有图中确有会干扰本镜的内容时才加入具体排除项，例如角色板上的旧服装与当前造型冲突。优先选择、裁切或派生合适输入。

原图的人、道具和光态在本镜会怎样用，由当前分镜决定。指向明确用途的短句通常足够；场景确有新动作、环境或文字时按场景需要描述。防御性描述仅保留对这次输出有实际作用的部分。

## 进入真实请求

在H3的subject_definitions或retention_analysis说明参考角色一次。新动作、揭示与声音发生点放detailed_description。当前选定的文件和上传顺序与这些标签对应。

绑定格式示例：

```json
{
  "allow": ["facial identity"],
  "deny": [],
  "prompt_quotes": ["<Picture 1> supplies facial identity."]
}
```

实际prompt包含引用的控制句，句中涵盖声明的作用。编译器优先复用已有句；缺失时补短句，空deny不生成排除文字。对确有冲突的排除项，同样核对其实际展开。

`check_request_bindings.py --require-control-scopes`检查请求、引用及版本。返回素材再判断输入是否真正达到预定作用，采用记录保存实际观察。
