# 短剧后期设计与生成交接

分镜定案和H3提交前阅读；实际后期技术与QC见 [post-finishing](post-finishing.md)。现有STORYBOARD拥有特效/剪辑卡，ASSETS拥有图形、遮罩、声音和接受文件，VISUAL拥有文字/材质/颜色/运动规范，采用/edit记录拥有真实时间。不要为“后期”再复制一套剧本。

剪辑/声音/效果的创作决定和文案由[当前Agent创作](../creation/document-writing.md)集中设计，仍归STORYBOARD/VISUAL等原责任文件。当前Agent负责实际工程、代理proof、底片/参数和声画检查；新的节奏、切点、揭示或声音表达应回当前Agent修订，不能在实施时暗改。

## 正规后期环节按本作实际需要组织

素材接收/时间与色彩解释 → 叙事粗剪/声音和特效代理 → 采用区间及画面版本锁定 → 特效交接/合成、标题包装、声音编辑/混音 → conform与色彩匹配/创意调色 → 字幕/多画幅/技术导出 → 真实出口QC和工程交付。特效和声音可以并行准备；依赖切点的最终处理以当前采用版本为准，改剪后重新conform受影响项。

不是每部短剧都需要复杂合成、降噪、超分、颗粒、插帧或花式转场。需要的是每项有导演用途、负责人、可执行素材与版本、真实输出和验收，而不是仅罗列软件或让一条FFmpeg命令承担所有艺术处理。

## 制作前划分 model / post / hybrid

| 类型 | H3负责什么 | 后期负责什么 | 生成前必须准备/预留 |
| --- | --- | --- | --- |
| 表演/真实空间事件 | 身体/手/道具接触、表情与听者、走位、遮挡、物理光影、真实机位变化 | 选取/剪接、必要局部修复与声画组织 | 可读的动作阶段、原生近景/反应覆盖、正确起止状态和可用余量 |
| 精确图形/艺术片名/字幕 | 干净且适合图形的底片，必要主体轮廓/留白与稳定视角 | 正确字形/排版、材质、逐字/遮罩浮现、描边/光扫、读停/退出、配套cue | 接受的文字/字体或图形资产、位置/层级、安全区、实际renderer/可替换参数和代表性渲染 |
| 剪辑转场/节奏效果 | 需要的动作出入、相似形状/运动或被遮挡底片、真实反应 | match cut、J/L cut、速度变化、定格、冲击帧、局部zoom/blur、色彩/声音桥 | 两端的匹配方向/状态、可用源区间、音画handle；不是每切都加转场 |
| 混合VFX | 与效果交互的表演、接触/视线、遮挡、动机光线和能跟踪的画面 | 透视/跟踪、遮罩/rotoscope、分层合成、粒子/辉光/冲击、反射/图形与声响 | clean plate/遮罩/图形、相机/平面关系、被遮挡区域与光照需求；无法获得则改生成/镜头方案 |
| 声音/调色 | 采用路线支持的同期对白/呼吸/现场声、清楚的图像曝光和材质 | 选用/补音/音乐与静默、混音、镜间平衡与创意色彩、最终编码 | 真实输入职责、原声/后期分工、已知色彩解释与代表帧；不能假称已有独立stem |

分工按控制需要选，不按效果名称武断划分。物理爆发/变身可由H3生成整合，也可混合；纯屏幕文字更适合确定性后期；世界中可触摸的招牌文字又需要透视/遮挡与真实场景。后期不能补回没生成的关键接触、演员新角度或丢失的反应。

微缩、关键同框尺度、多物体状态和特殊声音在分镜/构图阶段先选可实现方案。已有合成机制匹配时复用；否则比较局部补拍和有依据的覆盖改组，避免素材返回后才为单镜搭建抠像/跟踪工具链。需要新机制时小范围验证，后续复用；投入不能挤掉整场精剪与音乐设计。

声音默认分工及保留/补强/替换在[sound direction](../creation/sound-direction.md#h3原声为基础后期补强)保存。
沿用有效H3联合对白/同期声，配乐通常独立后期控制；不能为了统一后期自动弃全轨。
原声未检查时保持待判断，工程中不假称已有干净对白或独立stem。

## 一张效果交接卡写到可以开工

| 项 | 必须明确 |
| --- | --- |
| ID / 体验条件 | 对应EX/源细节/镜头，观众此刻知道与感受什么；不需要的效果明确不做 |
| 归属 | model / post / hybrid；各阶段要产生的具体内容及实际执行者/工具 |
| 素材与生成前提 | 底片/clean plate、图形/字体/alpha、遮罩、跟踪/透视、光影、音效、可用时长与版本 |
| 声画过程 | 起点→出现/变化→峰值→读停/反应→退出；采用动作/词/cue锚点；位置、范围、强度和声音关系 |
| 实现与proof | 代码/工程/参数、实际可用renderer、代表性输入与短段输出；计划、可执行proof、最终合成分别有状态 |
| 失败与接受 | 错字/伪影/遮挡失效/对不上动作/覆盖表演/提前泄密/损失余韵等具体失败；实际输出/区间与复查 |

关键或未验证的效果先做小范围技术/视觉proof，可用代理底片测试字形、mask、运动、alpha和renderer；不能把“后期能加”当成准备完成。依赖真实镜头的最终跟踪/合成只能在实际采用底片上接受。还未能实现的效果保留未决，改工具/素材/镜头安排，不无声降级为普通淡入或把压力转给H3。

## 艺术字片名浮现的具体制作

先读[片名设计闭环](title-design.md)：本页的renderer只实施已定字形和过程，
不拥有片名出场的叙事位置、字体选择或艺术接受。workflow/交付的titles声明由现有卡导出。

先接受字形和最清晰状态，再做显形过程。文字可以来自具体字体、矢量路径或接受的图形资产；浮现可采用局部mask/描边、逐字错位、材质/深度、局部光扫、粒子/墨迹等，只有本作需要才组合。字体、字距、材质、读停、退出与声音一起设计。只有opacity从0到1不是所有“艺术字浮现”的等价实现。

确定性实现优先走Hypit项目Track/HTML/SVG/Canvas或其HyperFrames渲染层；静态文字资源与动态显形分别拥有职责。复杂空间跟踪、rotoscope或3D效果采用实际配置的合成工具/工程，先验证能力。软件名、静帧截图和标题模板文件都不能证明最终效果。

附带 [build_title_reveal.py](../../scripts/build_title_reveal.py) 可以把本机字体的字形转为路径，制作一个可修改的**轮廓→纹理填充→局部光扫→读停→退出**HyperFrames工程，支持干净背景或透明层。它只是已验证机制的起点；参数中的演示色彩不是全剧默认，轮廓动画不是书写笔顺。

它输出`mechanism_proof_not_design_acceptance`，不证明该字体、字距、金属色或动画适合本作。
不为调用方便选择本机默认字体，不将工具时长直接插入电影；已接受定制图形不能无声换回
脚本字体。只在这个机制匹配已定设计时使用它，否则从接受的图形实现所需过程。

```text
python <skill>/scripts/build_title_reveal.py --text "当前片名" --font <实际字体文件> --out <独立效果工程> --overlay --gsap ./gsap.min.js
```

用当前HyperFrames CLI帮助确认check/snapshot/render与透明输出参数。提供实际GSAP依赖，检查工程及关键帧，渲染短段与alpha层后合成在本作底片上复看。当前验证的CLI版本为0.8.146；初始化会安装/刷新额外skill，可在已配置环境用进程级`HYPERFRAMES_SKIP_SKILLS=1`避免重复安装（该版本的`--skip-skills`本身不生效）。不为了一个效果重装运行环境。Hypit可将已渲染层作为显式素材参与当前Timeline/Film；安装本skill不会自动创建新的Surface或改历史工程。

本次Windows直接WebM渲染遇到本机进程错误，改用同一HyperFrames工程的`png-sequence`、软件GPU与本地FFmpeg编码，产出了实际RGBA/VP9 alpha。出现类似问题先保存工程与日志，采用已验证的后期导出路径；不能把“格式支持透明”当成alpha已保住。RGBA PNG序列也可直接交给合成器，不必强求同一种封装。

## 图形、颜色、音轨和采用版本的闭环

使用当前实际采用区间交接；保留足够余量但不把所有生成秒数剪入电影。直接从采用/工程记录导出本作需要的交接信息：

- 画面/剪辑版本、采用素材/区间/时间基准及当前构图/裁切/改速。
- 可播放的参考剪辑、实际动作/词/cue锚点与本项体验/信息条件。
- 原生/中间文件、已知色彩/alpha解释、图形/遮罩/跟踪/音轨/字幕版本及实际处理工程。
- 当前变化和只需重做的消费者；仍有效的文件/结果继续引用。

不要求新建一份交接文书或每项生产都转AAF/EXR；格式由实际工具接收能力决定。图形、遮罩和声音
跟随同一采用锚点；换镜/裁切/改速后只复查受影响内容。需要新的复杂工具路径时先让一段素材真实
往返并合成，核对时序、构图、色彩/alpha和声音；已有同配置有效proof复用，不为常规导出重复考试。

最终看与听完整编码结果：字形/显形/图层与背景成立，注意力与反应保住，声音/色彩跨镜连贯，效果没有替代剧情。代理proof只证明该机制/配置可用；真实整剧的效果强度、美感和体验需要在实际片中判断。

流程参考：Adobe的 [film/TV production workflow](https://helpx.adobe.com/au/premiere/desktop/get-started/preferences-and-settings/best-practices.html)、[text animation](https://helpx.adobe.com/after-effects/desktop/animating-text/text-animation/animating-text.html)、[alpha/masks](https://helpx.adobe.com/ca/after-effects/desktop/work-with-transparency-and-compositing/work-with-alpha-channels-and-masks/alpha-channels-masks-mattes.html)。借鉴交接/确定性字形与遮罩方法，不假定本机安装这些软件。

## 实际粗剪后的执行定案

生成前先定model/post/hybrid职责；采用后按[当前EDIT接口](editing-and-finishing.md)重新定位。当前Agent读取真实视频与独立字词时钟，给现有EDIT中的具体修改，不再输出只有grade_notes、音效类型名或“后期做”的空方案。复杂效果按既有字形/材质/遮罩设计渲染短透明层，画面颜色写成clip.grade，音乐/拟音/环境使用真实文件与事件锚点；先有可执行过程，再核对实际成片。
