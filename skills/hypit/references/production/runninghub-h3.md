# RunningHub H3: selected route and actual inputs

New generation uses the user's RunningHub MiniMax H3 app, the default instance, and images/audio only.
Video inputs are disabled, including source excerpts and generated continuation clips. All exposed
VIDEO fields are empty; no Video label enters the prompt. Source video remains local evidence.
The user's trial showed source-style leakage despite textual transfer scopes; do not restore this route.

Read the current [slot adapter](runninghub-slot-routing.md) and [production guide](short-drama-production.md).
The adapter discovers real nodes and uses their actual pointers, labels, upload values and receipts.
Credentials use RUNNINGHUB_API_KEY or, on Windows, the current user's encrypted
~/.hypit/runninghub/credential.dpapi; keep it outside the Skill, production documents and exports.
An app's physical video capacity does not authorize filling it. Existing plus/ultra selections are
rejected before upload/new task creation. If default resources fail, restructure the block or remove
redundant inputs within the accepted content/quality plan; do not automatically upgrade the instance.

The target look comes from accepted images, design and color cards. Source visual style is analysis
evidence, not the generation target. Four-panel character masters and on-demand scene overview/camera/state images supply identity/
space; concrete shot compositions and predecessor exit frames supply the current camera/state.
Write temporal acting, contact consequences, concurrent listeners, camera movement and reveal/cut
timing explicitly in the official H3 fields. A still is not a temporal performance lock.

Audio slots keep their actual reference/reuse purpose and speaker identity. Preserve usable H3 native
speech; post controls music, supplementary sound and mixing. Do not claim waveform copying/lip sync
from an audio slot alone. [当前Agent](gemini-audio-review.md) observes actual source/candidate/final audio.

Default submit checks the prepared request and current image/audio bindings, duration, default instance
and empty video inputs. Independent review and complete preproduction/workflow/allocation/transfer
packages are not required for ordinary recreation. Historical packages remain readable and can be
explicitly checked, under the same current input/instance restrictions.

Keep known task receipts before polling; observer timeouts are not remote failure. Resume/collect
the original task instead of new paid submission. Actual source/target comparison, single/boundary/
scene adoption, post execution and final audiovisual checking still determine quality.
