# 自主成片：精剪、声音后期与出口闭环

完整短剧委托默认一路推进到真实导出文件。用户既定Brief、账户、范围和预算覆盖本次制作、修复、后期和交付，不在听不到声音、缺常速观看、预演艺术检查不完整时反复请求“授权继续”或“授权暂用”。此页拥有执行策略；[接受证据](acceptance-evidence.md)拥有真实艺术检查状态。作者走当前Agent直接写作；视频仍为RunningHub H3。

## 准备时就确定可执行路径

沿用完整STORYBOARD、DESIGN/已有设计、必要时的完整剧情正文和导演/声音/效果方案，不另建主稿。完整制作默认autonomous_finish；仅在已有package/workflow/采用plan实际使用时同步此策略和当前版本，不为执行策略新增冻结包，恢复旧项目不沿用过期pass。先确认本地媒体处理、渲染、ASR、已有声音素材/账户和可选声画理解路径。工程中每个关键cue/effect有真实执行者；缺工具先用可用安装/本地替代解决，不能只写“后期处理”。沿用既有授权和预算；没有某个新服务的账户不强制登录或新增订阅。

缺连续看听能力时，当前Agent按“实际媒体 → 波形/声能/静音与技术测量 → 关键画面与边界 → 精剪 → 出口复检”推进。听不了就按数据大致判断节奏与接缝；台词、声线与听感未核实处注明，不再提交外部听审服务，也不因此卡住制作。

空间/持物/状态连续性按[实际状态交接](spatial-continuity.md)执行：用采用区间的清楚结果帧观察，机械承接到后继/真实请求；旧参考冲突先修，关键状态变化区间标required state_change，由retime保护。未知不填通过，修受影响镜头/输入后继续，不增加常规授权或独立审查。

## 执行一轮真正的节奏精剪

素材陆续返回就建立整场粗剪；生成期间可并行取音乐/声音素材和准备后续独立镜头，尽早让指定作者一起判断整场节奏、反应与音乐。按[复用执行](efficient-execution.md)消费既有记录，局部修复按理解/剧情后果/核心体验优先。复杂抠像或跟踪没有已验证可行路径时，先比较局部H3覆盖、构图改组和现成后期，不默认临时开发逐帧合成器。

粗剪形成后必须进入精剪，不能以全长H3片段直接拼接作为默认终稿。先按[实际对白保护](dialogue-preservation.md)取得已有字幕/词时间，或用波形粗定位声音活动，约束真实裁切；若保留对白与预期时长冲突，优先保对白并调整覆盖/局部速度，不先裁词后补字幕。现有编辑行记录实际source in/out、timeline in/out、对白/动作/揭示/反应锚点、切点理由及保留EX；原始片段留存。按本作目的选择需要的修复：

- 核对计划、粗剪、精剪、出口时长，解释增长落在哪些交流/动作/片名/余韵；时长增长只用于定位，不设统一失败比例。
- 查每镜句前等待、句末尾巴、镜对双重停顿、同强度解释累计和片名保持。使用[节奏精剪与局部变速](pacing-and-retime.md)记录实际变速区间、速度、理由和重对齐项；ASR语音空隙只是候选：动作、视觉信息、笑点铺垫、听者反应、音乐转折和余韵仍能在无台词时发展。
- 信息或反应已经完成的技术余量可收紧；必要反应与建立预期保留。对白跨镜、听者覆盖、J/L cut、声桥、动作接切和有动机的并行调度可以提高密度；局部声画同速变速可在不损伤表演时修整模型拖沓，速度改变后重新对齐字幕、片名、声音cue和后续入/出口。全片统一提速不是默认，不能凭节奏删除受保护的五类贡献。
- 对定位的问题作前后邻镜比较，累计看整场/整集；避免局部都“留一点”却总计拖慢。情绪转折、笑点、紧张和消化损失需要不同时间，不能把每处静默剪成同一长度。

新增创意切点/覆盖/表演要求交指定作者修订，GPT执行机械conform与已有作者切点，不在精剪中偷偷重写故事。无需每次切一下都换会话：按场次合批修订，再执行。

## 把声音做成实际终混

H3有效对白、语气/呼吸及同期音优先保留；后期承担缺失对白的可用替代、BGM、环境/拟音/设计音、声场接续、ducking/自动化和终混。具体处理由[声音导演](../creation/sound-direction.md#自主声音完成与配音修复)和[后期](post-finishing.md)拥有。必须取得实际音频文件、排到真实cue、导出并复检；“声音方案已写”不等于完成。不能因为没有听审能力就默认删原声、默认全片配音，或只加一条合成床就交付。

## 检查缺口不成为停工审批

中间复检以实际变化为范围：同源字节/采用区间/处理参数不变就复用证据，声变查声、图变查图，切点/速度/整体混音变则查相关声画和邻接。最终编码文件的完整对白、关键状态、累计节奏与声画回查仍覆盖；局部检查不能冒充整片已看听。

常速声画检查能做就做并覆盖真实最终版本；不能做时先尝试可用的文件/工具路径，然后仍完成可执行的生产和修复。使用[inspect_finishing.py](../../scripts/inspect_finishing.py)可扫描实际出口的解码、流/时长、静音候选、黑场/冻结候选、响度/true peak及可选台词时钟。其阈值用于诊断，不代表好看/听感/平台验收标准。密集帧与ASR不伪装常速连续看听。

`unverified`保留未观察事实；`failed`保留实际已知问题。可修的失败先局部改、复检，不把“缺证据”当作免做精剪/混音的借口。在授权预算内优先低成本编辑/后期，需补拍才回H3；两次针对性修复无改善就改方法，保留最好可用版本与确切剩余问题，不无限重生或自动扩大预算。已知关键内容损失仍不可宣称无损或艺术通过。

新策略的机器出口不要求填艺术pass：checker的`provisional`仍代表缺艺术证据，同时`execution_allowed: true`可以推进后继/后期/交付。需要同版本真实全区间解码/元数据诊断、现有修复记录，以及完整未通过项目清单。动态后继仍须从实际采用区间取得可见出口/派生图，不把预计状态当事实；声音身份/连续声若尚未确认，记录未知，不声称自动继承正确。

## 最后交付什么

交付实际成片、可继续编辑的工程/素材索引及现有DELIVERY说明。说明列实际版本/哈希、计划→粗剪→精剪→出口时长与关键改动、H3原声处理/后期声音资产和cue、图形效果实际完成情况、各检查范围、残留已知缺陷与未验证项及已尝试方法。主状态用：

- **已完成成片；声画检查完成**：实际完整声画覆盖及全部条件通过。
- **已完成成片；部分检查未验证/仍有残留问题**：生产/后期/技术检查做完，具体未通过项目如实列出；不称完整艺术验收通过，也不再要求用户授权暂用。
- **技术受阻**：缺必需输入、无有效媒体、无可用渲染路径、账号/预算等客观原因确实不能产生成片，说明最小缺口与已保留成果。

不要只交粗剪把必需精剪/配音/配乐/效果留给用户。不能证明的高级导演效果保留为未验证，但交付前尽可能执行已有条件能支持的制作。既有用户反馈可直接驱动修复，不增加发布数据/真实反馈定位环节。

## 方法与工具来源

2026-10-14联网核对[FFmpeg filters](https://ffmpeg.org/ffmpeg-filters.html)的silencedetect、loudnorm、blackdetect/freezedetect和sidechaincompress：支持测量与混音，不提供情绪判断。[WhisperX](https://github.com/m-bain/whisperX)用于对齐文字；[Qwen3-Omni](https://github.com/QwenLM/Qwen3-Omni)用于有可调用部署/账户时的实际音频/声画理解；[python-audio-separator](https://github.com/nomadkaraoke/python-audio-separator)用于具体混合干扰的按需分离。后两者都不是已安装能力声明；不强制下载大权重。GitHub三项目的方法参照本作2026-10-12已有官方资料研究；本轮raw地址连接失败，未据此宣称新模型/账户已接通。HyperFrames项目的音轨处理读已安装hyperframes-audio，素材获取读media-use；先确认具体账户/CLI可用，均沿用本作授权。

实际扫描调用示例（替换本作路径/已安装可执行文件）：

```text
python -X utf8 -B <hypit-skill>/scripts/inspect_finishing.py final.mp4 --output final.scan.json --ffmpeg <available-ffmpeg> --ffprobe <available-ffprobe> --planned-duration <editorial-seconds> --speech final-alignment.json
```

--speech仅有本次实际出口对齐结果时添加；旧素材的时钟不能套入精剪出口。完全无需换声音的镜头保持原混音，不盲目做均衡/分离。无法听音的技术诊断优先比较同一轨处理前后、同一空间相邻段及真实停顿；不同声线的频谱差异不能当失真证据。该判断借鉴本次已读hyperframes-audio的diagnosis方法；不照搬它在无听感结论时要求用户描述的步骤，改为交付未知并继续。

## 从真实粗剪推进到精修

当前默认后期执行入口见[素材到后期](editing-and-finishing.md)：将实际粗剪声画、必要完整分镜与原轨字词时钟交当前Agent，写可执行EDIT；finish_drama落实独立声画、局部速度、真实音乐/声音、颜色/图层、分轨/终混。实际导出后再诊断，局部修原配置并重新对齐，只补确实缺少的覆盖。目标选曲、音乐覆盖/停乐、乐句交接和自然收尾也参与这个循环。原曲不可得就按当前氛围选配，不把识曲失败当缺配乐的理由；完成可行处理并明确残留。
