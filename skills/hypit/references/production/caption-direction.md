# 字幕设计与情绪交接

当前Agent读取 DESIGN、STORYBOARD 的情绪发展和切点意图，在现有 EDIT 中直接落实触发、反应、兑现、字幕与声音主导层。

## 先看底片，再定字幕

选字体时看人物、画风、光色与语言。对白字幕以易读、稳定和留白为底，重点词、心声、系统文字与片名各有层级。先在真实代表镜头上比较安静与强调两种处理，选定一套全片基调，局部变化服务人物和情绪。

正文逐字沿用既有台词，实际发声决定 cue 起止；改速与声画分离后按编译时钟重算。长句优先按语义分行，整个 cue 保持原时窗；要分成先后出现的短句，就按实际子句边界定时。

EDIT 顶层 `caption_style` 可写 `{"preset":"cinema","font":"Noto Sans CJK SC","size":0.036,"bottom":0.17,"color":"#F4F1EA","accent":"#E4C78E","fade_ms":0}`；`clear`、`editorial` 是另外两个可调起点。单位为画布比例，具体值按本片选择。单条 captions 可加 `style:{"x":0.5,"y":0.72}` 避让，`keys:["重点词"]` 强调；`timing:"measured"` 或 `"reviewed"` 保留已经核准的源 cue，编译只负责映射成片时间。新样式使用随包附带的 caption_layout.py，无需另外安装 short-drama-edit；未选 caption_style 的旧工程保持原样。

`finish_drama.py EDIT.json preview.mp4 --preview` 使用同一编译时钟输出最大 540 像素宽的连续预览。正式版去掉 `--preview` 并用新输出名；字幕、声桥与转场仍按相同的事件关系执行。

竖屏以手机尺寸检查字形、字重、描边、行距和安全区。脸、手、证据或图形与字幕相撞时，用该 cue 的位置覆盖避让；多说话者通常靠镜头与位置识别，只在作品需要时使用颜色区分。

强调色从本片色彩里选，少量重点词即可建立层次。入场、强调和退出跟实际重音与反应呼吸配合；平静对话可以完全静态，冲击或喜剧段落可大胆做字重、尺度和局部运动。

## 节奏不断在交接处

前期已选的压力推进、笑点、揭示和余韵，按现有 anchors/事件引用落入 EDIT。每段精剪看它接住了哪个触发、保留了谁的处理、把什么情绪交给下一段。音轨、字幕、图形共用这些锚点，改源窗或速度时一起换算。

音乐以情绪段而非生成块为单位；复用主题、按乐句发展，在戏剧转折处定位音乐落点。卡点优先移动配乐源窗或不伤表演的切点；动作接触的拟音瞬态与观众理解的音乐重拍可以错开。实际看听前后连续段，判断是帮助表演还是抢走注意。

执行字段与命令仍见[剪辑接口](editing-and-finishing.md)，曲库与乐段选择见[音乐](music-selection.md)。
