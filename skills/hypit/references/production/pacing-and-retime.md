# 短剧节奏精剪与局部变速

短剧生成片不能默认把H3返回片段原速直接拼接交付。生成长度是原始覆盖，不是最终节奏。先按导演分镜与实际采用区间判断，必要时再做局部变速、删等待和声画重排。

先按[戏核与切点](drama-editing.md)选对表演/覆盖、组织反应和注意力，再进入本页的秒数与速度处理；原速与试速只比较有问题的相关范围，不额外给每镜产多版。

## 先诊断，再决定速度

这些是常见风险，不是已证实的H3固定参数：模型可能把语速、动作启动、运镜和句尾留白做得比目标原片宽松；单个4–15秒块也可能连续维持同一能量。不要把“120–130字/分钟”“统一1.2倍”或“每段必须2–4秒”写成硬标准，目前没有足够可靠的官方依据支持它们。

逐段对照原片与目标采用出口，记录：

- 句前/句后技术等待、双重停顿、动作启动前的无效帧和动作完成后的无效尾巴；
- setup→期待→揭示→反应是否已经完成，笑点/反转/关系变化是否还在发展；
- H3语速、听者反应、运镜速度、切镜时机和整场累计同能量交流；
- 需要保留的静默、呼吸、眼神、犹豫、揭示读停和余韵；
- 原片/目标的计划、粗剪、精剪、出口时长及差异归因。

ASR时间戳、silencedetect和波形只产生候选区间，不证明这里没有表演或故事作用。先在整场上下文决定切点；需要声音判断时使用真实音频听审。无效技术余量可收紧，受保护的台词、听者反应、因果线索和情绪落点不能为了快而删掉。

## 先保护完整对白

按[实际对白保护](dialogue-preservation.md)取得已有词时间或波形辅助的声音活动边界；保住词尾、气口与必要反应，再剪空白或调速。当前Agent时刻只用于定位，不能单独决定裁点。有真实字词时间时retime_finish保护相应发声区间；没有时保持当前Agent选定的源窗并标明近似；字幕跟随已有时间，不能靠显示完整文字证明音频完整。

## 速度策略

1. **优先剪空白和重排**：把必要对白跨镜、J/L cut、动作接切和反应覆盖放在更有效的时刻；移除已经完成意义的技术尾巴。
2. **局部变速**：只对有证据偏慢且不会破坏表演的连续片段变速。对白、表演、镜头和环境声需要一起处理；不要只加速画面而留下原声，也不要只拉快音频造成口型脱节。
3. **变速不变调**：有需要时在小段比较原速与适量加速，例如1.05、1.10或1.15倍；这些只是候选示例，不是每次必须生成的版本或统一上限。声音清晰度、角色质感、表演和动作决定采用哪一档；没有问题就保留1.0倍。全片1.2倍不能自动套用。
4. **分段处理**：变速边界放在镜头切点、动作阶段边界或无声/声桥安全点；跨台词中间切割会损伤词、口型和情绪。速度改变后重算字幕、片名、音效、音乐cue、声桥和后续入/出口。
5. **速度仍救不了时回到上游**：如果慢来自表演策略、H3没有完成动作、提示词缺过程、镜头覆盖少或原生同期声错误，回修分镜/提示词/局部补拍，不用全片加速掩盖。

## 可执行的局部变速工具

需要实际导出时使用：

    python <skill>/scripts/retime_finish.py input.mp4 pacing-plan.json output-v2.mp4

`pacing-plan.json`：

```json
{
  "version": 1,
  "segments": [
    {"start": 0.0, "end": 1.8, "speed": 1.12, "reason": "已有动作展开过慢，局部试速后保留完整动作和重音"},
    {"start": 1.8, "end": 5.0, "speed": 1.0, "reason": "保留对白、听者反应和揭示读停"}
  ],
  "anchors": [
    {"id": "line-1", "start": 1.9, "end": 3.2},
    {"id": "reveal-reaction", "start": 3.2, "end": 4.8}
  ]
}
```

segments直接由已有采用/剪辑记录机械导出，不新增一轮模型写作；start/end是本输入文件的实际秒数，未列出的区间被剪掉，段内speed=1表示保留原速。anchors可直接用已有逐字、动作或效果区间，脚本报告其完整保留、部分剪掉或移除，不把丢失自动判成通过。

脚本使用FFmpeg `setpts`处理画面、`atempo`处理声音，保持音高路径；会保存源/计划/结果哈希、源→目标时间映射和需重新对齐的字幕/后期cue。它只做技术conform，不宣布节奏或情绪合格。已有输出不覆盖。剪切后先用底片/同期声建立节奏，再安排后期配乐，避免反复拉伸已完成终混；H3自带混合音乐若被拉伸，另检瞬态、接缝和是否需要替换。

变速后必须：实际解码并核对时长；重新对齐字幕/片名/音效/BGM/声桥；检查口型、呼吸、语气、动作连续性和邻镜；整场及整集回看累计节奏。任何异常保留具体证据，必要时回退到原速或拆成更合适的剪辑。

## 生成前的适度补偿

H3视频参考槽仍停用，不能把原片预加速后上传来解决节奏。可在文字提示词中写本镜需要的语速、抢话、动作启动延迟、运镜速度和切点，但不要写无证据的统一字速数字。目标节奏由详细分镜、短块时钟、实际采用和后期共同决定。

## 声音和音乐不能只用来遮慢

BGM、鼓点、拟音和声桥可以强化动作落点，但不能用固定音乐循环盖住慢表演、掩盖缺对白或提前泄露反转。音乐进入/退出、音效瞬态和静默保留必须回到声音卡及实际出口。H3有效同期声先试听，再决定保留、局部修复或后期替换；变速不等于自动重做所有声音。

## 成片验收

自主成片至少记录：计划→粗剪→精剪→出口时长；**源片→出口的总时长差、剪掉的源秒数、变速实际节省量和选中素材的有效平均速度**；每个变速/删空白区间及理由；受保护体验是否仍可感知；字幕、声音、片名、特效是否重新对齐；实际正常速度声画检查范围；未验证项和残留问题。若总时长明显增长而没有新的叙事/情绪职责，必须再做一次整场累计节奏精剪；不能用“局部已有1.05倍/1.1倍”代替整体节奏判断。技术扫描只报告候选，不能替代真实声画判断。

“正常速度”指精剪后最终文件在播放器1×播放，允许文件内部已经采用局部变速；不要求把最终文件恢复成H3原生时长。当前Agent听审同样提交实际精剪出口，以该文件时钟重新取音频；旧原片/粗剪ASR、听审和截图时钟不能套用。

方法核对（2026-10-15）：[H3官方基础指南](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md)明确多镜头和切镜时钟，不支持“15秒必然单镜”的断言；[FFmpeg滤镜](https://ffmpeg.org/ffmpeg-filters.html#atempo)提供atempo、trim/atrim与setpts；[Premiere速度与时长](https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-speed/change-the-speed-and-duration-of-clips.html)说明变速时保留音高。它们支持实现方法，不证明统一字速或1.2倍能改善所有短剧。

## 主动精剪与实际采用

节奏处理每次执行判断。对实际偏慢素材，主动试温和加速并采用有效结果，可先在代表段试1.05/1.10/1.15，再用于相同问题的连续范围；不为形式固定生成三版。**局部试速后还要看全片出口的累计时长和能量曲线；如果额外覆盖、重复等待或镜间空档抵消了局部节省，必须回到选镜、J/L cut和并行反应，而不是继续叠加倍速。**保留情绪停顿、反应和完整对白，必要时回调原速。避免统一1.2不是默认保留全部原速。剪辑作者以实际素材选择切点，不必保留每个生成块。

多镜头声音跨切、配乐、字幕与颜色/图层用[finish_drama时间线](editing-and-finishing.md)。当前源→成片映射按最终帧时钟，独立音轨按48k样本时钟，图形/音乐用事件锚点重算；先稳定画面/同期声节奏，再重组独立BGM乐句。已确认的额外原声按review证据处理，不因保护完整台词恢复无用重复。
