# 当前Agent直接创作

剧本、设计、分镜、提示词、字幕和后期决定都由当前会话Agent完成，使用Agent本身可用的模型能力，不再调用外部作者API或切换另一个模型。

读取当前范围的原稿、参考事实和已有决定，按任务选择短剧或通用格式；写入原来的文件所有者，回读并同步实际消费者。同一Agent完成创作、核对和执行，不需要把自己的判断再送给外部作者确认。

短剧仍沿用25列源表、26列新分镜及当前旧稿表头；通用口播、访谈、讲解、屏幕和MG按[通用创作](../general/writing.md)选择适合的文稿、场景说明或镜头表。图像、视频和声音输入能由当前Agent实际读取时就直接用；不能读取的部分保留为未知，不编造成观察。

已有大型批次可选用 `write_drama_documents.py run <request.json>` 整理 `agent-context.json`，由当前Agent读取并直接写目标文件。这个命令现在只整理上下文，不发送模型请求，也不是每次写作的前置。普通任务直接读写即可。

旧外部调用已返回的内容可用 inspect / recover / adopt 恢复，不重投；历史作者与费用回执保留原事实。新创作不再需要分析API Key。
