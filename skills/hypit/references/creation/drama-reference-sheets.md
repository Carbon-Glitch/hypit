# 短剧资产：角色四宫格、按需场景总览与关键状态

制作资产时与 [资产台账](asset-plan.md)、[色卡](style-lock.md) 一起使用。图板是可复用的视觉控制源，各格不是多个不同人物、地点或连续剧情镜头。内置imagegen失败时按[生图备用](../production/image-generation-fallback.md)携带同一提示词/锚点/参考图继续，角色和空间规范不变。

## 角色：一张 2×2 四宫格

默认顺序：左上正脸头像/半身，右上侧脸头像/半身，左下正面全身，右下背面全身。上排兼顾清晰五官和肩胸服装，下排从头到脚完整可辨；按需调整格子面积保证脸和服装都有有效分辨率。侧脸明确左右方向，并核对不对称特征。全身含头、手、脚，背面能读后脑/发型与服装结构。

同一人物、身份与当前造型版本，统一中性姿态、背景、布光和尺度关系；各格脸型、年龄、头身比例、发型、左右配饰与服装正背结构一致。使用项目选定的视觉媒介，背景服务辨识，摄影棚光不能被当作所有正片的照明。

首次先接受清晰的身份锚点，再以它派生其他视图并完成四宫格；现有角度图可整理成母版，缺失项再补。生成一张整板或逐格制作后合成都可，但不能让四格分别发明身份。极端表情、伤态、雨湿、变身、重要动作/接触按分镜另外补，不塞进基准板。新服装/形态用新 look 版本，沿用同一身份。

原创填写骨架：

```text
用途：角色 <ID> / 身份版本 / 造型版本的可复用四视图母版。
依据：当前人物档案 + 接受的身份锚点 + 视觉规范版本。
布局：一张2×2图；左上正脸头像半身，右上<左/右>侧脸头像半身，
左下正面完整全身，右下背面完整全身；每格同一个人、同一套衣服。
身份：<可见面部、体型、发型和辨识特征>。
服装：<内外层、领口、闭合、袖口、腰线、鞋履、正背结构及色材>。
捕获：<当前媒介>；<中性背景和可辨识照明>；完整展示各格职责。
保持：<实际身份/左右特征/服装版本>。边框和标记只用于管理。
```

## 场景：3/4斜视总览为主，机位与多视图按需

普通单镜背景、无跨镜约束的陈设可直接由H3生成。对会跨镜复用、走位/道具关系影响剧情的地点，先接受一张目标画风的3/4斜视总览：可读的门窗、通道、主行动区、家具/关键物件、尺度和光源。俯仰为可读性服务，不硬定45°，不为看见全部摆件强行做剖面房。

为需要反打/明显遮挡的角度补对应机位图；九宫格只在确实需要多个视角时使用。所有视图从同一已接受布局派生，核对门窗、数量、路径和投影，不能把一次生成九格视为天然一致。平面图/白模负责推理，送视频的具体起点优先使用去掉标注、符合目标画风的单张构图。

基础布景与当前状态分开。椅子被踢倒、杯子被拿起、门打开后，关键后继使用实际结果帧或最小局部编辑后的当前状态图；旧位置应为空，不在新图里复制出第二个物件。状态图按变化制作并复用，能抽帧就不再生图，不给每个镜头默认首尾两张。

状态图来自实际采用区间能看清结果的帧，不机械取整段生成末帧。最后是脸部特写时，结合最近可见证据与状态记录；新机位从空间母版＋有效状态派生，避免一代代重画累计漂移。具体交接见[空间与状态](../production/spatial-continuity.md)。

多人交叉、复杂遮挡、反复失败时才用简单3D布局导出必要机位静态图；720全景适合固定中心环视背景，不能替代可移动三维几何。要互动的椅子、门、杯不能只烘焙在背景里。3D、全景、深度图均不是全片前置。

## 道具与附加参考

关键道具按需单张，必须看清形状、尺寸、材质、持握、开启/损坏等剧情状态。只有反面结构或状态揭示确实被镜头消费时才加角度/状态。重要证据文字按阅读与揭示条件安排，不能用通用“无文字”把它抹掉。

表情/接触参考、站位/轴线图、声音样本和故事板承担独立职责。它们补充角色母版与场景总览，不能以整齐的图板代替具体表演、时间和声音。

## 入库与真实请求

`ASSETS.md` 记录母版文件/哈希/版本、格号与职责、身份/造型/地点状态、色卡版本、消费者、逐格与整板检查、接受证据。检查串脸、左右镜像、缺脚/裁头、服装正背冲突、空间不连通和色彩漂移。

角色母版以四宫格交付；场景保存实际所需总览/机位/状态图，九宫格按需。为生成提取干净单格或派生构图图，登记 `parent + panel + crop/处理 + resulting hash`。提取之后复看有效五官/材质细节，单格像素不足就以已接受母版派生更清晰视图，不靠放大宣称新增真实细节。

按 [真实参考职责](../production/reference-scopes.md) 与 [输入绑定](../production/request-controls.md) 把最终选用图上传、绑定并检查回执。整板在参考模式可尝试用作多视图记忆，须排除边框、文字、重复人物及多画面输出，并用真实试拍验证。I2VA/FL2VA 的首尾帧用干净单幅构图，不能把四/九宫格当首帧。H3 槽位不足时从母版选最相关单格或接受的集成镜头图，保住身份/布局/状态控制；色卡可通过场景图和展开文字传递。图板入库规范不意味着每次上传全部格子。
