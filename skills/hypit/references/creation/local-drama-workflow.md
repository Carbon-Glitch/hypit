# 本地短剧工作流

短剧、漫剧、剧情复刻与续集按本页继续；其他视频按根入口路由。

## 五步主线

当前步骤只加载入口及实际遇到的问题页，已验证结果直接复用。

1. **拉原片。** [25列源表](../../references/creation/source-shot-analysis.md)记录全范围镜头、因果/知情/铺垫兑现和实际声画，关键动作与疑点局部密读。共同/E/EX、卖点、声线与分阶段音乐放SOURCE_CONTEXT；[听审](../../references/production/gemini-audio-review.md)核实声音，[交互回看](../../references/creation/source-review.md)按需派生。
2. **写通目标。** [必要前期](../../references/creation/drama-preproduction.md)将变化与视听方向落入DESIGN、26列STORYBOARD。完整动作/对白、听者、起终状态和切点承接源义务。时长容纳完整发声及串行动作；真正有风险的语言/接触/空间/揭示段落才预演。
3. **备资产、生成。** [资产](../../references/creation/asset-plan.md)先判复用、变体、瞬态与持续关系，每张图有实际消费者。[H3写法](../../references/playbooks/craft/h3-prompts.md)描述具体过程、起终构图和必要受光结果。[队列](../../references/production/efficient-execution.md)合批、缓存、恢复；稳定事实可并行，动态后继等实际采用状态。
4. **素材回来就剪。** [剪辑接口](../../references/production/editing-and-finishing.md)先记可用带，再选叙事入出点；将前期触发、反应、兑现和音乐发展绑定到真实源事件，选择表演/反应和声画覆盖，裁等待，按需局部保调变速。真实选曲试听与生成并行，[音乐](../../references/production/music-selection.md)、卡点、[字幕设计](../../references/production/caption-direction.md)、颜色与图形在最终画面时钟落入同一EDIT。
5. **修复、验收、交付。** 中间回查改变区间及邻接，[对白](../../references/production/dialogue-preservation.md)按真实发声边界保护。最终文件解码并完整正常速度看听，核对源义务、状态、累计节奏、音乐进退及后期完成。按[自主交付](../../references/production/autonomous-delivery.md)提供成片、可恢复工程与具体残留。

## 一份事实，一个所有者

SOURCE_SHOTS＋SOURCE_CONTEXT拥有源证据；STORYBOARD拥有普通复刻的动作/准确台词；DESIGN/ASSETS保存必要设计与实际参考；EDIT/采用记录拥有真实区间和后期操作。新增剧情、大幅改因果或独立剧本委托时使用完整文学稿作为故事/台词所有者。

PROGRESS只留当前缺口、任务ID和下一步，DELIVERY只记实际出口和回查结果。执行包、队列及快照由工具派生。旧49/44列表可读，显式迁移另存；新表可选项无内容留空。细节见[归属与恢复](../../references/creation/project-files.md)。

写作优先描述实际要出现和发生的内容。泛化防御条款省略；具体参考冲突、隐藏/揭示或已发生错误需要限制时，只在相关位置写一次。实际结果与预期分开，未验证处保留未知。
