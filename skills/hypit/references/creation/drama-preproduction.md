# 短剧前期：完整信息与单一主稿

复刻、改编、原创或续集需要补前期设计时读。日常执行见[生产简表](../production/short-drama-production.md)；本页定义必要信息及其归属，不要求五份独立文件、固定轮次预演或额外提交包。已有接受稿直接复用，只补本次变化及实际依赖。

## 五类内容怎样承接

| 内容 | 必须能支撑制作的信息 | 默认归属 |
| --- | --- | --- |
| 世界 | 时空、社会/技术/超自然规则、限制与代价、空间关系；规则怎样驱动冲突与揭示 | DESIGN世界章节；已有WORLD可继续用 |
| 人物 | 全部有叙事作用的角色；欲望/障碍/策略、关系与知情变化；造型/服装状态、声线和表演差异 | DESIGN人物章节；已有CHARACTERS可继续用 |
| 视觉与声音原则 | 媒介/材质/光色/摄影语法、全局及特殊场景实际色卡、代表帧；声音主题、听觉视点与后期分工 | DESIGN视听章节；已有VISUAL可继续用 |
| 完整故事 | 从开场到结尾的因果、全部行动/对白、听者反应、信息顺序、铺垫兑现与余韵 | 普通复刻由完整STORYBOARD承载；新剧情、大幅改变动机/规则/因果或独立剧本委托写完整剧情正文 |
| 可执行镜头 | 26列目标分镜，具体动作/表演过程、摄影、状态、声音、时长切点、资产和model/post/hybrid职责 | STORYBOARD主表及必要的同一场次详情 |

文件名沿用项目；DESIGN也可合并委托事实、导演选择和资产索引，不要求另建BRIEF/TREATMENT。只写本作有作用的内容，必要事实不能因“只写变化”而遗漏。稳定事实可引用现有已接受正文；未知标明，不能由新设定倒填原片。

**每类事实只维护一个权威正文。** 普通复刻的STORYBOARD拥有完整行动与准确台词；不另转写源SCRIPT或目标SCREENPLAY。需要文学稿时可用SCREENPLAY或DESIGN内的完整剧本章节，故事/对白以该处为主，分镜忠实展开成表演与覆盖。SVML及H3是派生执行稿；对白变化回到当前权威正文再同步消费者，不维护两份可独立改写的台词。

完整以委托范围为准：一集写完一集，整部新作写完委托范围，不能以前几集正文加后续大纲冒充。没有提供的前史/后集保留未知；续作只补实际依赖的既有规则与前集采用状态。只委托拉片/剧本/资产时交付该阶段。

## 从整体剧情落到镜头

原片的完整25列源表保留全部镜头证据；SOURCE_CONTEXT保存整体和跨镜关系。整体理解不能只在发现复杂问题时才做，也不需要另写一轮全剧摘要。用已有场次/EX记录建立以下关系，简单作品简写，复杂处展开：

- **因果与策略**：谁想得到什么、遇到什么阻力，人物的哪次选择导致下一局面和代价。
- **知情与关系**：人物/观众此刻各知道什么、误解什么；对白和行动怎样改变权力或亲疏。
- **信息与体验**：线索何时植入、何时允许揭示；铺垫→期待→揭示→反应→余韵如何跨镜完成，笑点/紧张成立需要哪些细节和停顿。
- **状态与承接**：时间地点、站位视线、持物/接触、服装和声音在前后镜怎样连续；结尾留下什么结果或未兑现承诺。

目标的改编选择放DESIGN导演章节或现有Treatment，关联源证据/EX→本次变化→目标机制→必要顺序/覆盖→丢失信号。完整目标分镜按顺序读通全部交流与行动；不能只核对每格非空。新增剧情先把因果、知情和完整对白写通，再展开镜头。这里是同一次写作与采用的内容检查，不增加独立报告或审查链。

原片[整体解构](source-deconstruction.md)、[逐镜方法](source-shot-analysis.md)、[体验保真](fidelity-contract.md)分别提供方法；[十三维分镜](storyboard-craft.md)只将本镜相关决定写入26列主表，不另填评分表。[改编与口语](adaptation-and-dialogue.md)和[吸引力/节奏](attention-and-rhythm.md)在出现相关问题时读。

## 场景生命与视听调度

分镜前按[场景视听调度](audiovisual-orchestration.md)主动判断持续环境、配角/听者、动作反馈、空间光影和画外声音。把有效选择写进现有目标行或场次详情，再交H3编译；不能因“一个主要变化”让主角以外无因冻结。主次、反应延迟、余动及声画关系比运动数量重要，安静与静止须符合现场和导演意图。

## 资产、过程与后期

按[色卡](style-lock.md)建立全局定调和有动机的局部变体；按[资产母版](drama-reference-sheets.md)制作角色四宫格；跨镜地点默认3/4斜视总览，必要机位/状态图与九宫格按需，道具只为实际消费者制作。精确当前构图用单张；资产接受与H3运动/表演接受分开。空间轴线、尺度、光源和状态只对实际连续性问题补充，不批量制造无消费者的图。

目标行提前写[声音](sound-direction.md)和[效果分工](../production/post-design.md)：H3承担表演、接触、现场光影及可用同期声，后期承担精确文字图形、剪辑、音乐/补音和混音。关键未验证效果按需做代理proof，最终跟踪/合成回到实际采用底片。首帧描起点、尾帧描终点，视频提示词[展开全过程](../playbooks/craft/h3-dense-direction.md)。

表层变化的复刻复用原片的动作/切镜/声音时序分析；目标语言、动作/空间或揭示切点变化时，仅对受影响段落补读演/临时声画预演。原片过程不证明新演员/资产/口型已合格。先试真正未知的难点和邻镜，不为满足文档数量延迟试拍。新生成固定RunningHub H3 default，图片/按需音频参考，全部视频槽留空。

## 每次写作请求带什么

创作统一走[当前Agent写作](document-writing.md)。全剧/改编开发读取完整源表、跨镜关系和必要设计；局部资产/H3提示词只发当前完整目标行、对应源行、依赖的EX/共同记录及必要原文切片。选段涵盖完整刺激、行动、揭示、反应及前后状态；场外伏笔/知情条件按实际依赖带入，不能仅按相邻镜号截取。

世界规则、人物欲望/知情、禁止提前泄露的信息、视觉/声线原则，以及必要前后镜的状态和对白，都必须有实际正文。文件名/hash仅用于本地追溯，不是远端模型已读证据。执行包自动投影，详见[镜头执行包](../production/shot-execution-packet.md)；不另写一份缩薄的故事摘要。最终H3只呈现可拍的行动、表演、摄影、声音和切点，不倾倒源分析论证、私有ID或全剧历史。

## 变更与成片

改变世界/动机/因果时更新实际故事主稿及受影响分镜；改变对白/动作/揭示时同步提示词、声音与剪辑；改变画风/色卡时复查受影响资产及采用；改变采用区间时刷新后继起点、cue和字幕。只重开受影响项，保留已接受结果和真实任务/费用记录。

[单镜→镜对→整场](../production/scene-acceptance.md)检查实际采用区间，[后期](../production/post-finishing.md)完成精剪、声音、片名/字幕/合成和色彩。最终回查完整体验链及整体累计节奏，不把字段完整、生成成功或局部漂亮当成全片成立；执行与残留项按[自主成片](../production/autonomous-delivery.md)处理。

需要填写示例时读[内容模板](drama-document-templates.md)；来源与案例边界见[方法依据](drama-method-sources.md)。
