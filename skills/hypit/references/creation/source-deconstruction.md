# 原片整体解构与改编增值

源片阅读、改编开发，以及局部正确却全片平淡时读。此页拥有**整体结构、风格发展、文化功能和源片提升诊断**；[reverse script](reverse-script.md)拥有原片交付，[reference events](reference-events.md)拥有逐镜/关键内部过程和EX单元，[aesthetic direction](aesthetic-direction.md)拥有目标导演构思。源分镜表保存声画事实，SOURCE_CONTEXT保存本页分析（已有ANALYSIS可作为依赖复用），Treatment选择目标方案。章节可短，引用已有ID，不增加核心文档或第二套数据库。

## 从完整作品建立层级

[内容守恒](content-conservation.md)要求从原片独立冻结情节、逐次台词、镜头语言、可观察
导演作用和观众体验五类索引。不要只提炼主要主题/反转；这些源记录的完整性必须回原片
核对，不能按已写的新稿挑选容易保留的条目。不同重要度用于排查，非删除授权。

在源观察里显式保留短小但承载吸引的机制：误会式问答、基准与落差、具体荒诞、
日常反例、人物间的回击/讽刺、享受开端、听者反应、关系缓和和声音揭示。
它们关联原始细节/EX，不能在目标开发时只剩主题摘要。按
[改编与对白](adaptation-and-dialogue.md)区分真实矛盾、可读省略与个人优化偏好，
再用[吸引力/节奏](attention-and-rhythm.md)检验替换是否保住观看过程。

先确认本次原片与目标范围，以及能访问的前后依赖。按[source audio policy](../production/source-audio-policy.md)完成实际可检查的完整画面及文字/声音读取，并明确原片声音延期范围；同时建立整体印象和场镜索引；密读解决有意义的细节/歧义，再用证据修正整体解释。**整体→场次/段落→跨镜体验单元→关键内部过程**是分析层级，不是重复播放或逐层重写全文的配额。正常播放与针对性的密读各有职责。

每项分析区分：实际观察；有证据的解释及合理竞争解释；未知；真实观众反馈。作者私下意图只在有实际陈述时归因，不能把预测体验写成观众事实。只得到一集/片段时，整季结构和片外世界保持未知；需要跨集证据才追读相关集，不自动扫描其他项目或虚构前史。

## 卖点分析：从“好看”变成可拍、可剪、可配乐的承诺

按[卖点与全片情绪配乐](selling-points-and-score.md)从原片证据恢复具体吸引机制，放进现有SOURCE_CONTEXT；目标表承接镜头、表演、剪辑与声音取舍。它决定哪些过程和落点要重点拍、重点剪、重点用音乐托住，不是再写一份营销概括。

## 全片和跨集结构

在SOURCE_CONTEXT.records保存跨镜机制和提升候选，关联EX/场次/细节；已有ANALYSIS可直接作为声明依赖，不重写。只回答本作适用问题，不为每个问题建文件：

| 关系 | 应从实际作品恢复什么 |
| --- | --- |
| 观看承诺 | 谁的什么处境首先吸引人；观众期待哪类回报；题材/表演强度和期待何时建立或被有意改变 |
| 冲突发展 | 欲望与障碍，人物选择/策略如何使下一局面发生；代价、风险和不可逆后果是否累积 |
| 场次贡献 | 本场进入/离开的信息、关系与压力；兑现/推迟哪项回报，给下一场留下什么必要条件 |
| 人物与对照 | 目标、公共策略/私人态度怎样变化；对照人物/关系如何让选择具有分量，不只给人物贴身份标签 |
| 全片疏密 | 信息、策略、情绪、动作和声画注意力的集中/释放；快慢与静动怎样共同形成整体，而非每拍平均加信息 |
| 伏笔与余波 | 植入→强化/误读→兑现/重释→反应/后果；尚未结清的承诺、关系和代价及其证据范围 |
| 主题问题（若成立） | 人物选择、对照和结局提出或复杂化什么问题；允许开放、矛盾和纯类型快感，不补道德总结 |
| 连续剧机制（若适用） | 什么母冲突持续制造新局面；每集如何有局部结果又承接累积变化；重复是否有升级、变奏或代价 |

不硬套三幕、英雄旅程、每集悬崖、固定秒数钩子或统一情绪曲线。类型承诺也不是默认题材禁令。六项核心体验是常用检验视角；具体作品的认同、尴尬、羞耻、敬畏或矛盾余韵按实际证据表达，不要求每场表达同样情绪。

## 事件时序、呈现时序与可知边界

顺叙且清楚时一句话说明即可；倒叙、重演、多视点、隐藏前史、平行行动等复杂处，在SOURCE_CONTEXT跨镜记录展开：

| 事实/源细节ID | 世界中发生顺序与时间证据 | 原片呈现位置 | 人物/观众当时可知内容 | 延迟/省略/重复的功能与未知 |
| --- | --- | --- | --- | --- |

区分“观众后来才看见”和“事件后来才发生”。实际先后未能确定就保留未知/多种解释，不用拟写的目标世界规则补原片缺口。恢复世界/社会规则的证据、行动代价、角色相信的规则和反例；没有展示例外并不证明不存在例外。

对关键揭示明确：现在必须可见/可听的线索；暂时不能获知的事实；释放触发；太早或太晚会损失什么。检查**所有载体共同形成的信息**：脸/手/道具/文字/背景/旁白/声场/音乐，不仅主画面。画外存在、没有反打、没有解释或声层退出可以承载意义；只记录对理解/期待有影响的缺席，不逐项登记所有没拍过的东西。不能靠隐藏一切制造无内容悬念。

## 恢复随剧情发展的声画语法

逐镜事实仍归SOURCE_SHOTS；SOURCE_CONTEXT归纳少量有证据的规律、例外和变化。观察距离、共享框/分离、深浅空间、运动/保持、焦点/遮挡、光色/材质、声场/音乐、切镜与母题，怎样与人物处境、权力、亲密或知情位置相关。

```text
规律/变化：实际源段落与细节ID → 可观察关系 → 可能的戏剧作用/竞争解释。
范围：何处成立、何处改变、哪些条件尚未知。
目标选择：DESIGN导演章节/现有Treatment解释转译；DESIGN视听章节/已有VISUAL拥有规则、变体与实际参考，分镜指明发生处。
```

不是求镜头平均值、摘一张漂亮帧或固定电影参数。重复出现的物件、声音、构图和颜色需记录意义是否改变；有意维持单调、仪式或停滞也可成立。形式自由允许新的语法，所保留的体验、因果与关系必须仍可检验。风格一致性包含有动机的发展，不能让色卡/参考资产锁死整部作品的变化。

## 潜台词和文化功能

把有作用的称呼、礼貌、沉默、手势、证物、制度和身份关系联系起来：这句话/行为实际上在试探、施压、讽刺、保护、拉近还是保全面子，谁理解或误解，权力/面子/利益代价来自哪里。世界常识与行为依据也要有源证据。

目标换语言、时代或世界时，Treatment说明要保住的行为功能、自然的新载体、预期收益/损失和验证。目标人物为何会这样行动必须可信；直译、演员换脸、欧美=克制、加俗语或自动删除陌生文化都不能替代转译。只对当前有影响且不确定的文化/术语做可靠来源核查，实际目标语言反馈和导演判断分别记录。未委托发布/联系观众不扩张为外部测试。

## 找到源片提升机会

先建立原片有效机制，再对照本次需求识别真正的问题。SOURCE_CONTEXT保存候选，Treatment选择与执行；不能把新方案写回源分镜表，或为证明改编成功改写原片事实。未发现有依据的提升时记录判断与范围，不强造问题或变化。

| 诊断 | 要定位的损失，不能只贴“模板/平淡”标签 |
| --- | --- |
| 因果/选择 | 巧合、廉价自曝、角色无理由放弃容易办法、世界规则突然解围；人物策略是否真正推动后果 |
| 策略/后果重复 | 相同质问/否认/证据揭示不断重来，筹码和未结清代价却不发展 |
| 过度解释/收口 | 动作已表达意义却再心理翻译；每场总结封死余波；抹掉观众推断空间 |
| 信息与读感 | 声画文字提前泄密、证据读不清、理解负担过大、过晚释放导致因果不可读 |
| 节奏/表达 | 无作用等待、每句同一微动作/推镜、平均信息密度、装饰特效抢走反应；也检查本应保留的停顿/疏密 |
| 体验未落地 | 希望没有建立、听者反应缺失、冲击没有后果、结尾余韵被截断，或音乐代替可信表演 |

重复问题需要实际可比的源位置；单次类型惯例不证明疲劳。重复笑料、仪式、人物口癖、固定机位和刻意停滞可能正是吸引力。区分：有证据的理解/因果问题、待实际反馈确认的体验假设、审美偏好。不要用“更高级”否定观众可能喜欢的原作机制。

候选记录按需放SOURCE_CONTEXT/Treatment既有记录，不设数量配额：

| 源证据/EX | 有效机制与问题/确定性 | 用户变化及候选新手法 | 预期收益/可能损失 | 实际执行条件 | 能推翻判断的验证与决定 |
| --- | --- | --- | --- | --- | --- |

常规形式改进在已授权范围内选定并记录；关键未决取舍比较真正不同的观看机制，复用[aesthetic direction](aesthetic-direction.md#比较真正不同的方案)。只改变衣服/形容词不算增值。H3较容易实现可作为可行性依据，不能冒充体验提升；增加一项亮点不能抵消另一项关键体验损失。改变核心体验或明示保留形式时才解决该范围决定。

## 从解构承接到制作和成片

Treatment关联 **源证据/EX或整体关系 → 用户变化 → 所选新机制 → 收益/风险 → 必要先后、覆盖和验收**。整体规律可用现有场次/EX引用，不要求把每项主题解释转换成一条镜头任务。

DESIGN/已有设计正文承接新作规则、人物策略与声画语法；完整目标分镜承接全部行动/对白和镜头覆盖。新增剧情或大幅改变动机/规则/因果时先写完整剧情正文，可合并章节，不强制拆成独立文件。预演比较完整单元及其邻接状态，试拍验证真正未知控制。每个关键拍注明实际承载的镜头/声cue/效果和必须存活的阶段；备用、补拍、handles只为具体编辑风险准备，不默认每拍多版本。

H3正文只展开当前块需要的表演、空间、注意力、信息和声画变化，并绑定实际输入；源论证、私有ID、历史与研究引用不倾倒进模型提示词。原片时间定位证据，目标时间重新读演，实际采用时间驱动声音/图形/字幕和后继。后期交接按[post design](../production/post-design.md#图形颜色音轨和采用版本的闭环)使用同一真实采用版本。

最终[scene acceptance](../production/scene-acceptance.md#check-the-whole-commissioned-work)在委托范围内回查：承诺兑现、人物/关系/后果发展、信息顺序、风格变化、伏笔与余韵，以及所选改善是否真的成立。局部细节都出现不保证全片有效。实际观察、导演解释、用户接受和目标观众反馈分开；成片不依赖制作说明才可读。
