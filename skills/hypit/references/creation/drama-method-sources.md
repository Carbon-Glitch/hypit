## 吸收和修正

| 手册环节 | 当前 Hypit 可保留的基础 | 此次补强 |
| --- | --- | --- |
| 立项/剧本 | Brief、Treatment、逆向剧本、戏剧因果 | 委托范围、五类必要内容合并、单一故事主稿与执行编译、跨集伏笔/知识/关系 |
| 人物/场景/风格 | 资产台账、身份/造型版本、cinematic look、style lock | 角色四宫格、场景总览与按需多视图、状态/机位派生、全局与特殊场景真实色卡 |
| 分镜/站位/关键帧 | director blueprint、scene design、animatic | 文字分镜保存意图和过程；起点图/终点图/视频全过程各有职责 |
| 提示词 | H3官方模式与严格格式、request bindings | 刺激→行动→接触→反应→揭示→保持，精确声画与剪辑接口 |
| 量产/修复 | calibration、回执恢复、场景采用 | 保留失败原因/修改/成本；从代表难点试拍到批次，采用秒数驱动后继 |
| 音频/后期 | 声音计划、H3能力核验、post-finishing | 角色声线进入档案，台词/反应读演先行，分轨及实际出口复看 |
| 上线/复盘 | 实际交付验收 | 按委托补平台出口、过程归档与真实反馈；当前要求临时核验，不预设发布授权 |

不照搬手册的30天/30集、8–10镜、9–11秒、禁BGM、固定负向前缀、LoRA阈值、供应商分配、废片倍率或“必达”百分比。镜数、运镜、声音、表现强度按本作体验和可执行路由决定。手册反对拼图的建议由用户图板要求取代，用有效单格分辨率与提取输入解决其实际担忧。HEX用于描述与比对颜色角色，不保证生成像素；种子/多图/图板均不是一致性保证。

复刻的核心标准由用户指定：**体验保真、形式自由、改编增值**。用独立源片证据保住好奇、幽默、期待、紧张、反转冲击与情绪余韵，逐项检验新的视听机制；漂亮的新外壳或一项增值不能抵消另一项核心体验损失。

## 声音流程补强（2026-10-10）

新增 [声音导演](sound-direction.md)，并连接角色档案、文字分镜、真实音频绑定与
原有声音/艺术接受。专业模块和第一手导演访谈的来源及不采用的固定规则在该页列明。
声音以观众听觉位置、信息/情绪变化和角色策略为依据，而不是固定层数/音乐/静默配额。
同日只读核对《完蛋》第三集实际runner及已保存请求：缓存schema有音频入口，但runner
未上传/绑定声音，属于尚未实现的执行环节。这次技能补强没有修改历史剧集runner，
也没有把档案中的样本或schema的存在报告成已实现声线控制。
