# 原片取证与交互回看

先复用实际切点与25列SOURCE_SHOTS，用本页组织初读和回查，不另写一份精简shots主稿。原表、SOURCE_CONTEXT和已有听审拥有事实；HTML、联系表与测量manifest都是机械派生视图，不授予艺术通过。

## 从同一源表生成

```text
python <skill>/scripts/source_review.py SOURCE_SHOTS.csv --output checks/source-review
```

默认读取表旁SOURCE_CONTEXT.json中的实际media.file/hash，也可明确--context和--media。输入需沿25列模板；初读底稿的未分析列可明确写UNKNOWN，不必先写完语义才抽图。复用本地PyAV/Pillow，不调用模型、不重编码原片，不另装Node或拉片框架。

派生文件：index.html、source-review.json、frames/、sheets/和.cache/。HTML内联表和公共记录，可搜索所有维度，按镜长或未知/提示筛选；原片播放同步高亮，点击镜头/时间轴跳转，逐镜展开当前表的全部字段、关联公共记录、声音与未知。视频仍读原文件；浏览器限制本地路径时自行选择对应原片，不能把选错文件当源证据。

原视频不嵌入HTML。页面和图片可离线打开/移动，分享时保留frames/sheets，接收方另提供同版原片。读网页和看图不等于模型已听声音，台词/音乐/特殊声线仍走既有Agent声音观察与波形辅助。

## 成对联系表用于初读，不代替过程

每镜默认取15%/85%附近、位于[start,end)内的实际解码帧，页面同时显示请求时刻与实际PTS。保留全部短镜，不自动合并0.3秒以下镜头，不根据主体运动/转焦新增切镜。成对联系表每页按同一镜号/顺序排列a/b图，先建立内容与状态概览，再定位疑点。

关键台词、听者反应、接触/转移、揭示、短文字和状态变化仍回实际中段密读，必要时用现有hypit media frames/tiles --at/--every-frame或已有视频代理。首尾相似不能证明中间没有动作；两帧也不证明完整运镜轨迹。缺少可用原生帧明确标缺，不拿邻镜或补画冒充。

## 运动量只给复查线索

默认最多5Hz采样原生帧，缩64×36灰度，计算相邻样本平均像素差，再取镜内区间中位数；剔除接近切点的样本。只在较长镜头、足够内部样本、文字含明显运镜词且变化低于经验值时提示复查。不把固定镜头中的主体活动判为运镜，不由数值推断方向、轨道/变焦或导演效果。

低对比、缓动、特效、曝光和主体运动都会影响数值。提示不等于错误、失败或必须重生成；回看后更正源表，或保留实际解释/未知。--no-motion可只出表和图片，--motion-hz/--low-motion仅调整辅助采样/提示阈值，不设每片全量门禁。

## 只更新派生资产与受影响理解

图片缓存按媒体hash、真实源窗、抽样参数和运行时识别；运动轨按媒体hash与采样参数复用。改文字不重抽帧或重测轨；更正一个边界只更新相关图片，其他镜号及已分析结果保留。报告永远使用源表镜号，不自动recut或顺序重编号，E/EX/义务引用继续有效；确有边界变化由既有源表处理下游关联，不从报告反写。

GPT用联系表、实际回看和提示定位原表需要补读的字段，只补受影响的事实、义务和目标输入；不再让模型重写一遍简化拉片报告。必要提示可作为已有写作inputs携带manifest，但不能把像素统计当听审或语义判决。

方法借鉴reelbench-skills的[video-shots](https://github.com/eternityspring/reelbench-skills/blob/df39d5df9d7adc2f82acba5594579d60361a42c7/skills/video-shots/SKILL.md)中成对联系表、运动矛盾提示和播放器联动；本实现适配Hypit源表与稳定ID，不移植其窄schema、15项门禁或全体重编号，也不重复模型分析。
