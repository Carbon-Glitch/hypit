# 内容守恒：只能保留、替换或增加，不能无对应减少

本安装的短剧复刻、限定改编、重构和已接受原创稿修订遵循严格 **no_loss**。
导演意图、观众体验、情节拍点、台词及镜头表达逐项保留或以不弱于原项的方式替换，
新内容另外增加。不能用总字数、镜数、文档长度或一个新增亮点补偿另一项被删。
此规则覆盖分析→文学稿→分镜→资产→H3请求→生成采用→剪辑→实际出口。

## 先冻结原有内容，不从改编结果倒推基线

源分镜表/ANALYSIS从实际原片独立读出五类清单：

| 清单 | 不能丢掉的独立贡献 |
| --- | --- |
| plot | 行动、阻碍、反例、误解、策略、选择、代价、因果前置与后果 |
| dialogue | 每次发声及回应，实际信息、人物战术、口气、言外之意、重复/打断/停顿的交流功能 |
| shot_language | 每个镜头/声画段的构图、视点、距离、调度、注意力、运动、切点、揭示、反应、光色或声音表达职责 |
| director_intent | 从具体声画推得的导演作用及其依据；有作者实际陈述才写为作者意图 |
| audience_experience | 好奇、期待、幽默、反差、紧张、理解、情感变化、关系和余韵的完整展开 |

每条关联实际源细节与更细的obligation。原观察、解释、未知和观众反馈继续分开。
缺少某一类时要有实际观察缺席的证据；未听/未看不等于该类不存在。不得编造私下意图，
也不得因无法知道私下意图，就删除能够观察到的导演表达功能。

按[source audio policy](../production/source-audio-policy.md)选字幕＋画面先行时，先以实际字幕/画面
建立本次有依据的清单，原声未核实范围明确单列；不把它填成observed_absence或凭空加语气/音乐事实。
已经核实的声音义务仍守恒，新片声音设计归目标，最终不宣称未比较的源声音已无损保真。

源目录必须与完整原片及有效上下文比较：只列最终结论、忘掉短问答/情绪基准/反应的目录
不能通过。源清单和读取判断先冻结；后续不能为了适配失败素材删ID、降级、缩写成一个主题。
真正源事实纠错保留旧版本，依据原素材重新阅读并使所有受影响比较失效。

原创首次创作从委托建立这些目标；首次接受的文学/导演稿成为后续改写的approved_draft
基线。已有基线不能在换编剧模型或“再优化”时假装重新从零开始。

## 对应规则：一对一或一对多，不把两项缩成一项

目标完整分镜用现有源镜头/义务字段承接每项源贡献，DESIGN仅解释有实际差异的改编选择。
一个源条目可由多个目标镜头共同完成；同一目标镜也可承接多个义务，但各项作用、时序和可观察结果
必须分别成立，不能用一个笼统“已保留”抵扣。新增写N/A:新增。不另建target entry或五类目标清单。

允许合并H3生成块、改变摄影覆盖或在一个连续镜里完成多次注意力转移；被合并的导演作用、
交流和体验仍须各有独立时序/表达与实际证据。镜头物理数量不是镜头语言的全部，
但是“多镜变单镜”不能抹掉任何原有视点、揭示或反应。

替换必须逐项比较：信息/因果与人物策略、可观察形式/时机、表达强度与观众效果，
结论为preserved或equivalent、loss=none、strength=not_less。较弱、未验证或只说
“主题一样”都不能释放依赖批次或完整艺术接受。分镜中导演意图/观众体验的文字不能缩成
泛泛标签；写得更多也不是银幕实现更多的证明。

## 台词保留以作用和真实发声为准

源台词逐次对应目标表达，保护铺垫、追问、反例、自我安慰、讽刺、回击及必要普通交流。
用户要求逐字复刻时逐字保留；授权改编时可用更自然的目标表达，逐项核对信息、人物策略、强度与节奏职责。
不以同语种字数不得减少、总字数或机械比例证明保真，也不为凑字扩写废话。未授权的整句/作用删除不能以
“冗余”解释。真实剪辑仍保护已确定的准确台词，不能用字幕掩盖缺音。

时间或模型限制冲突时，优先调整覆盖、生成块和声画并行，不擅自减少已承诺的观看体验。

## 每个阶段用同一组ID核对

1. **文学开发：** 写作模型收到原片/读取记录、五类清单、逐项对应及no_loss；不只收到已经变薄的摘要。
2. **分镜/预演：** 对应导演作用、观众体验、台词和拍点，保证单元结论、铺垫和反应都在；时序/可读性有疑点才做局部可回放预演。
3. **资产/输入：** 参考与构图必须承载对应表达与可读状态；不能以人物相像或空间一致代替表演/镜头职责。
4. **真实请求：** 每个obligation有实际prompt/input/post carrier；全部保守词、负面模板和节奏指令不能擦掉所需强度。
5. **生成与采用：** 看/听实际区间，记录保留/等价/失败/未验证，不从目标字幕或请求文本推定演员真的完成。
6. **剪辑与后期：** 只剪无叙事职责的技术余量/坏帧；保护铺垫、交流、揭示、反应、留白职责和后果。
7. **最终出口：** 按源义务和目标行核对实际输出；台词要有真实听觉范围，
   字幕、ASR、漂亮静帧或未剪入尾部均不能代签。

失败回最早错误责任层。切掉坏动作后关键意义也没了，应补拍/改覆盖，不得把相同损失写成
“等价改编”。新演员、新世界、新编剧提供者和新的剪辑节奏都受同一守恒约束。

## 记录与现实边界

源表贡献索引和目标行承接保留，具体[字段映射](../production/detail-transfer-format.md)由现有工具派生。
普通制作不再写allocation/transfer/target inventory、workflow或acceptance plan。现有主稿与实际采用区间
足以承载逐项比较；[接受证据](../production/acceptance-evidence.md)直接记录观察和缺口。
源目录的机械一致性与真实请求绑定仍检查，机器不认证实际看听、情感效果或导演私下意图。
没有证据证明保留或不弱替换的部分不能标艺术通过；缺失/未知具体定位并修复。
