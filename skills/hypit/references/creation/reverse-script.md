# 原片逐镜逆向交付

用于拉片、复刻及源片驱动改编。先确认完整媒体可访问；按[逐镜多维拆解](source-shot-analysis.md)和[镜内过程/EX](reference-events.md)读取实际声画，整体结构、文化机制和提升机会参考[source deconstruction](source-deconstruction.md)。

## 单一源主稿

- `SOURCE_SHOTS.csv`：全部原镜头的25列观察、解释、过程、台词、切点、体验、证据及制作贡献索引。这张详细表直接指导制作。
- `SOURCE_CONTEXT.json`：媒体/已有读取证据与完整源时段的绑定，公共场次事实、关键E/EX、未知声音，以及确有作用的全片机制/提升候选。只记录无法合理放在某一行的跨镜内容，表内以ID引用。
- 原剧本`SCRIPT.md`、ANALYSIS/TIMELINE、Markdown/XLSX阅读视图按明确需求或既有有用材料使用；不再要求新项目重复写一套逆向文学稿、逐镜摘要和总表。原剧本由表导出；已有文件是辅助输入，冲突回原媒体修正主表。

先核所有镜头边界和全范围覆盖，再逐场次填同一主表。固定两秒网格只用于概览；台词、听者反应、接触/转移、揭示、文字和声音变化须密读真实过程，关键段用已有E阶段扩展并核邻镜。首尾状态、起因与峰值/收回、知情差和切点职责不能被一句剧情摘要替代。观察、导演作用推断、未知与目标选择分开；不伪造焦距、未听声音或私下意图。

只有字幕时保留逐字台词依据，其他声音未知按[源声音策略](../production/source-audio-policy.md)处理；继续可执行分析/制作，不另请求继续授权。新片声音由目标导演设计、可用H3原声和实际后期完成。

## 直接交接

将源表/context作为[指定写作输入](document-writing.md)。源贡献索引由脚本自动派生版本契约，目标剧本/详细分镜按Brief保留或增强其有效机制；形式可改。保留或增加的动作、反应、镜头、声cue、切点和后期职责必须有实际承载方式与失败条件。目标分镜不能仅复制源镜号与情绪形容词。

不因目标台词齐全、镜头数相等、文档齐全或校验通过声称完整理解或体验保真；最终比较实际采用的声画过程。委托仅逆向时交付主表/context及必要证据；委托完整制作继续既有资产、生成、精剪、声音和最终出口闭环。
