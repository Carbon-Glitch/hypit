# 通用视频：按当前问题进入

口播、播客、街访、榜单、讲解、产品演示、MG和短剧可以组合。只读取这次需要的页，不把格式当作必须完成的阶段。

## 先定观看关系

| 作品由什么推动 | 路由 |
|---|---|
| 一个人直接向观众表达 | [UGC/口播](references/playbooks/formats/talking-head.md) |
| 两个人的观点、交谈和反应 | [双人播客](references/playbooks/formats/two-person-podcast.md) |
| 现场问题、被访者与揭示 | [街访](references/playbooks/formats/street-interview.md) |
| 项目逐项进入、排序和比较 | [榜单清单](references/playbooks/formats/ranking-listicle.md) |
| 主讲人与可视化论证共同发展 | [主讲人视觉讲解](references/playbooks/formats/presenter-led-explainer.md) |
| 独立旁白组织画面和证据 | [旁白主导](references/playbooks/formats/narration-led-demo.md) |
| 人物选择与行动改变关系 | [本地短剧](../creation/local-drama-workflow.md)；原生工程可参照[上游短剧](references/playbooks/formats/short-drama.md) |
